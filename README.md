# AI Workflow Learning Kit

**Explore online:** [Open the AI Workflow Learning Kit website](https://luckygithub777.github.io/ai-workflow-learning-kit/). Discover clear, evidence-led templates for focused work.

Three blank, reusable templates for evidence-based work with human judgment.

- [Decision-Ready Brief](templates/decision-ready-brief-template.md) — frame the decision, evidence and recommendation.
- [Source Map](templates/source-map-template.md) — record source quality, uncertainty and gaps.
- [Risk Map](templates/risk-map-template.md) — evaluate possible failures, mitigations and accountability.

Fill in the templates using authorized, verified information. Use fictional examples when sharing work publicly. They do not connect to accounts, send data, execute decisions, or establish measured performance.
